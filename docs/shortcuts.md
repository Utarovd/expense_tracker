# Автоматизации iPhone («Быстрые команды»)

Адрес вебхука: приложение → Ещё → Настройки → «Адрес для Быстрых команд» → Скопировать. Он секретный.

## 1. СМС банка (карта UZS ···3153)
1. Приложение «Быстрые команды» → вкладка «Автоматизация» → «+» → «Сообщение».
2. «Отправитель»: выбери контакт/номер 5800 (или впиши 5800). Сообщение: любое.
3. Отметь «Выполнять сразу», выключи «Уведомлять при запуске». Далее.
4. «Новая пустая автоматизация» → добавь действие «Получить содержимое URL».
5. URL: вставь адрес вебхука. Нажми «Показать больше»: Метод `POST`, Тело запроса `JSON`.
6. «Добавить новое поле» → тип «Текст», ключ `sms`, значение: переменная «Вход команды» (Shortcut Input) → выбери свойство «Содержимое» (или просто «Сообщение»).
7. Готово. Когда придёт СМС от 5800, запись появится сама, а в Telegram придёт сообщение (для нового магазина с кнопками категорий).

## 2. Apple Wallet (Apple Pay: карта UZS и Visa)
1. «Автоматизация» → «+» → «Транзакция».
2. Выбери карты (Visa и UZS-карту, если она в Wallet), «Выполнять сразу», без уведомления. Далее.
3. Действие «Получить содержимое URL»: тот же адрес, Метод `POST`, Тело `JSON`.
4. Добавь три поля (все «Текст», значения: переменная «Вход команды» + нужное свойство):
   - `amount` → свойство «Сумма» (Amount)
   - `merchant` → «Продавец» (Merchant)
   - `card` → «Карта или пропуск» (Card or Pass)
5. Для Visa в `card` должно быть слово Visa в названии карты (так сервер понимает, что это счёт Visa в USD).

## Как это склеивается
- Оплата Apple Pay картой UZS может прийти и из Wallet, и из СМС: сервер объединит их по сумме и времени (в пределах 15 минут) и запишет один раз.
- «IYB MOBILE EXCHANGE» записывается как перевод Карта UZS → Visa. Сумма в долларах оценивается по курсу продажи банка и помечена как оценка: поправь по факту.
- Остаток из СМС (Qoldiq) сверяется с приложением: при расхождении в Telegram придёт предупреждение.
